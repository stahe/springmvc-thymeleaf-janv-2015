# Introduction à Spring MVC et Thymeleaf

👉 **Accéder au cours en ligne** :  
https://stahe.github.io/springmvc-thymeleaf-janv-2015/

## Présentation

Ce document a pour objectif d’introduire, à l’aide d’exemples, les notions fondamentales de **Spring MVC**, un framework Web Java reposant sur le modèle **MVC (Modèle – Vue – Contrôleur)**.

Spring MVC fait partie de l’écosystème **Spring Framework** et fournit un cadre structurant pour le développement d’applications Web Java robustes et maintenables.

Le cours présente également **Thymeleaf**, un moteur de vues moderne et puissant, particulièrement bien intégré à Spring MVC.

## Public visé

Ce cours s’adresse à des lecteurs disposant d’une **bonne maîtrise du langage Java**.

Il n’est **pas nécessaire d’avoir des connaissances préalables en programmation Web**, les concepts étant introduits progressivement.

## Portée du document

Bien que relativement détaillé, ce document ne prétend pas être exhaustif.  
Spring est un framework vaste, composé de nombreuses briques et extensions.

Le document a été conçu pour pouvoir être **lu sans ordinateur**, ce qui explique la présence de nombreuses **copies d’écran**.
